    Istruzioni

    0. Mettere VocalCue comodamente sul telefono

    Salva questo file HTML in una cartella dedicata sul telefono, ad esempio chiamata VocalCue — la stessa che userai per i file audio.

    Android (Chrome): apri il file da Chrome, tocca i tre puntini in alto a destra, scegli "Aggiungi a schermata Home". Da quel momento avrai un'icona che apre l'app a schermo intero.

    iPhone (Safari): apri il file dall'app File scegliendo "Apri in Safari", tocca l'icona di condivisione in basso, scorri e scegli "Aggiungi a Home".

    1. Progetti

    Un progetto raccoglie le canzoni di un corso, una classe o un musical specifico (es. "Musical classe A", "Coro del giovedì"). Crea un progetto, poi aggiungi al suo interno tutte le tracce che ti servono per quel gruppo. Puoi passare da un progetto all'altro dal menu in alto in qualsiasi momento.

    2. La cartella VocalCue

    Crea una cartella chiamata VocalCue sul tuo dispositivo: lì terrai tutti i file audio usati nell'app, organizzati automaticamente in una sottocartella per ogni progetto.

    Computer (Chrome o Edge su Windows/Mac/Linux): tocca "Imposta cartella sul dispositivo" qui sopra e seleziona quella cartella una volta sola. Da quel momento, quando carichi un nuovo file audio, viene salvato lì automaticamente — e viene ritrovato da solo ogni volta che riapri l'app.

    Android e iPhone: questa automazione non è disponibile sui telefoni (è un limite del browser, non dell'app). Copia prima manualmente il file audio nella cartella VocalCue (tramite l'app File o Google Drive, salvandolo da Mail, AirDrop, iCloud o Drive), poi selezionalo dall'app quando richiesto. Il nome del file atteso è sempre indicato accanto al nome della traccia nel menu a tendina.

    Suggerimento — usare Google Drive come cartella: se hai l'app Google Drive installata sul telefono, puoi tenere la cartella VocalCue dentro Drive invece che solo in locale. Così, quando l'app ti chiede di selezionare un file, Drive comparirà tra le origini disponibili nel selettore, e lo stesso file sarà automaticamente presente anche sugli altri dispositivi collegati allo stesso account — senza doverlo trasferire a mano tra telefoni. Resta comunque una selezione manuale ogni volta (il file non viene "ricordato" da solo), e se non è già scaricato sul dispositivo serve una connessione internet per recuperarlo.

    3. Marcatori

    Metti in pausa la traccia nel punto che vuoi memorizzare e tocca "Segna questo punto": ti verrà chiesta un'etichetta (es. "Ritornello"). Tocca un marcatore nella lista per far ripartire la traccia esattamente da lì. Ogni marcatore può essere rinominato o eliminato singolarmente.

    4. "Mantieni in memoria su questo dispositivo"

    Opzione alternativa alla cartella (utile anche su iPhone): salva il file audio direttamente nel browser, fino a un massimo di 5 file in totale su tutti i progetti. Se provi ad aggiungerne un sesto, l'app ti chiederà quale dei 5 eliminare per fare spazio.

    5. Eliminare una traccia o un progetto

    Su computer (Chrome/Edge), quando elimini una traccia ti viene chiesto se vuoi cancellare anche il file fisico dalla cartella o solo rimuoverlo dall'elenco. Su Android e iPhone, l'eliminazione rimuove solo la traccia dall'app: il file resta nella cartella (locale o su Drive) e va rimosso manualmente se non serve più. Eliminare un progetto elimina tutte le sue tracce e marcatori.

    6. Esportare/importare la configurazione

    Il pulsante "Esporta configurazione" scarica un file JSON con tutti i progetti, le tracce e i marcatori, utile come backup o per trasferirli su un altro dispositivo. "Importa configurazione" ricarica quel file.

    7. Link YouTube

    Per una base karaoke da YouTube, incolla il link: il video resta visibile nella pagina (è un requisito di YouTube), ma puoi comunque segnare punti precisi e farli ripartire da lì come con un file audio.
